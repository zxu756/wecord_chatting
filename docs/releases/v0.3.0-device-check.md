# v0.3.0 真机检查清单

切 `main` 之前，在真机上走一遍。每项打勾或记下问题。

## iPhone
- [ ] 应用锁：Face ID、失败后用设备密码；锁住的聊天推送只显示「你收到一条新消息」。
- [ ] 圆形视频：首次授权相机和麦克风、按住录制、回看、发送；聊天里静音循环、点开有声音。
- [ ] 阅后即焚：查看时截屏，对方收到「已被截屏」；控制中心录屏时画面被遮住。
- [ ] 通话字幕：两台设备通话，开启字幕，句子出现；结束后生成纪要笔记。
- [ ] 视频字幕（CC 按钮）。
- [ ] 日常：拍照、录视频、发布、查看、回复。
- [ ] 关怀模式：大字、简洁首页、朗读消息。
- [ ] 离开自动回复：对方发消息后收到一条自动回复，约一分钟内有推送。
- [ ] 本机 AI（iPhone）：不支持 Apple Intelligence 的机型上，设置 → AI 那一行显示原因、开关不可点，摘要和翻译照常走服务端。

## Mac
- [ ] 应用锁（Touch ID / 密码）；窗口失焦再回来时的锁定时机。
- [ ] 圆形视频：摄像头出画面、能发送。
- [ ] 白板：触控板双指平移、捏合缩放；鼠标滚轮与 Cmd+滚轮。
- [ ] 本地缓存加密：首次启动钥匙串有没有弹窗；设置 → 存储页「本机保护」显示正常。
- [ ] 本机 AI（需 macOS 26、已开启 Apple 智能）：设置 → AI 里「优先使用本机 AI」显示可用；聊天摘要、输入框改写、消息翻译能完成且不占每日 AI 额度；关掉开关后改走服务端；先跑一遍 `tool/on_device_ai_check.sh`。

## 网页（Chrome、Safari）
- [ ] 通行密钥：先在 Supabase 控制台开启 Passkeys，再创建、用它登录。
- [ ] 两步验证恢复码：丢掉验证器后用恢复码登录、重新绑定。
- [ ] 圆形视频（MediaRecorder）录制和发送。
- [ ] 公开圈子页 `/c/<短名>`、邀请页 `/invite/<码>` 在别的 App 里预览卡片。
- [ ] 开发者文档页 `/developers/` 能打开。
- [ ] 离线时搜索出现「离线结果」。

## 一起看（两台设备，一台当主持人）
- [ ] 主持人分享直链 MP4：对方自动开始播放；暂停、拖动后对方 1–2 秒内跟上。
- [ ] 分享 mp3 链接「一起听」；最小化到悬浮小窗后声音继续，通话声音不被抢走。
- [ ] 分享 YouTube 链接：卡片提示无法同步，「在应用内打开」/「在浏览器中打开」可用。
- [ ] 主持人离开通话：对方的一起看结束并有提示。
- [ ] 网页端 Chrome：HLS 链接显示不支持提示；自动播放被拦时点一下能加入。
