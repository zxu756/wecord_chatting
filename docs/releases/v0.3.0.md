# WeCord v0.3.0

第一个阶段版本：扩展路线图里不需要拍板、不花钱的功能基本做完（114 项里上线 80 项）。
下面是 v0.2.0 之后上线的内容，按方向分组。

## 聊天
- 加急消息与「需确认」公告（A7）；重复的定时消息（D4）。
- 引用部分文字回复、静默发送（A9）；语音消息倍速、连播、暂停续录、裁剪（A10）；关键词特效（A12）。
- 快捷短语（输入 `/短语`）与离开时自动回复（A8）；圆形视频消息（A13）。
- AI 回复建议「帮我回复」，只填进输入框、不自动发送（F6）。
- 机器人交互组件：按钮、下拉、表单与回调（I1）。

## 社交与内容
- 日常（24 小时动态）与密友（B1）；朋友圈 2.0：提醒谁看、置顶、3 分钟视频、发到聊天、评论配图、图片描述（B2）。
- 收藏 2.0：分组、标签、搜索，可收藏链接、笔记、朋友圈和圈子帖（B3）。
- #话题与圈子帖子 2.0：标题、话题、精华、列表/网格（B8）。

## 圈子
- 版主工具 2.0（限期封禁、话题锁定、申诉、批量处理）与突袭防护（C5、C6）。
- 成员荣誉与头衔（C7）；圈子知识库（D6）；媒体频道与问答频道（C9）；活动 2.0：重复、报名问题、名额与候补、签到、活动相册（C10）。
- 公开圈子网页与漂亮的邀请链接 `/c/<短名>`、`/invite/<码>`（C8）。

## 协作
- 笔记 2.0（表格、评论、模板、导出、发布网页）与笔记 AI（D5、F5）。
- 任务清单 2.0：自定义字段、子任务、重复、日历视图（D7）。
- 群空间：群相册与群文件夹（B6）；群打卡（D3）；群标签页（D8）。
- 工作流自动化（D9）；白板（D10）。

## 语音与通话
- 通话字幕与会后纪要，本机识别、不录音（E1）。
- 语音频道状态、网络质量提示、仅音频模式（E6）。
- 预约通话（E2）。

## AI
- AI 问答：问聊天记录、答案带出处（F1，第一阶段）。
- AI 守护 2.0：投票、标题、可选的图片检查（F7）；反诈提示与链接安全检查（G5）。

## 隐私与安全
- 应用锁与聊天锁（G2）。
- 两步验证恢复码；网页版通行密钥（G4，需在 Supabase 控制台开启 Passkeys）。
- 高级聊天隐私：禁止复制、转发、保存和 AI 读取（G6）；阅后即焚的截屏/录屏提示（G7，仅 iPhone/iPad）。
- 本地缓存加密与离线搜索（G8、L3）。

## 平台、性能与无障碍
- 存储空间管理（L2）；无障碍 2.0：在线状态形状、聊天字号、图片描述、视频字幕（L8）；关怀模式（L7）。
- Android 网页适配、iPad 适配、PWA 分享到 WeCord（H1 阶段 0、H4、H12）。
- 大群/大圈子性能优化：成员分页、推送分批（修好了超过 1000 人收不到推送的问题）（L6）。

## 运营与开发者
- 产品统计、自建监控告警、错误报告 2.0（K2、K3、K5）。
- 出站事件订阅、Bot API 2.0、开发者页面（I2、I3）。

## 还没做的
- 要花钱、要 Apple 开发者账号或要母语者校对：E4、F8、I6、L5、L9、L10，以及 9 项 Apple 账号相关功能。
- 需要拍板：18 项（商业化、端到端加密、原生 Android 等）。
