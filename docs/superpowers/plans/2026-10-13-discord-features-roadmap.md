# Discord 风格功能清单（Roadmap）

参考 Discord 的公开行为，在 WeCord 现有的 Flutter + Riverpod + Supabase 架构上重写，不搬运 Discord 代码或品牌元素。
每项开工前先在 `docs/superpowers/specs/` 写设计说明，确认后再实现。完成后在这里勾掉。

工作量：**S** = 一两天以内，**M** = 需要新表/新 RPC + 较多 UI，**L** = 涉及外部服务或大量客户端工作。

---

## 已完成

- [x] 宽屏圈子工作区：圈子图标栏、频道侧栏（分类可折叠、未读标记）、内嵌频道聊天、成员列表开关
- [x] 媒体页 / 成员资料页改为 push，返回后保留圈子状态

## 第一批：推荐优先做

- [ ] **消息表情回应（Reactions）**（S）
  - 新表 `message_reactions (message_id, user_id, emoji)`，唯一约束 + RLS：只有会话成员可读写
  - 长按消息菜单加常用表情，消息下方显示「👍 3」小标签，点一下切换
  - 私聊、群聊、圈子频道都能用
- [ ] **「新消息」分隔线 + 跳到最新**（S）
  - 用现有 `last_read_message_id` 在打开会话时定位分隔线
  - 不在底部时，右下角显示「跳到最新」按钮
- [ ] **固定消息（Pinned Messages）**（S）
  - 群和频道里管理员可以钉住或取消单条消息
  - 顶栏 📌 按钮打开固定消息列表，点击跳到原消息
- [ ] **圈子邀请链接**（S–M）
  - 新表 `circle_invites (code, circle_id, created_by, expires_at, max_uses, use_count)`
  - 生成、复制、撤销链接；通过链接加入的 RPC 校验过期时间和使用次数
  - 路由 `/invite/:code`，打开后先显示圈子预览，再点击加入

## 第二批：增强圈子

- [ ] **频道分类**（M）：自定义分类，频道可以拖拽排序、跨分类移动
- [ ] **成员列表按在线状态分组**（S）：复用现有在线状态，分成「在线 — n」和「离线 — n」
- [ ] **圈子级通知设置**（S）：整个圈子免打扰，或只在被 @ 时通知
- [ ] **圈子内昵称**（S）：每个圈子可以单独设置显示名
- [ ] **圈子图标栏未读点**（S）：需要后端按圈子汇总频道未读数
- [ ] **窄屏 / 手机版圈子布局**（M）：图标栏 + 频道列表并排，滑动切换到聊天

## 第三批：消息体验

- [ ] **简单 Markdown**（M）：粗体、斜体、`行内代码`、代码块、> 引用、||剧透||
- [ ] **链接预览**（M）：Edge Function 抓取 Open Graph 信息并缓存，消息下方显示卡片
- [ ] **子话题（Threads）**（M）：从某条消息开子讨论，频道侧栏显示活跃的子话题
- [ ] **连续消息合并**（S）：同一人几分钟内连发的消息合并显示，只在第一条显示头像
- [ ] **自定义状态**（S）：头像旁显示「🎮 在打游戏」这类状态文字

## 第四批：权限与管理

- [ ] **自定义角色**（M–L）：带颜色的角色，成员列表按角色分组
- [ ] **频道权限覆盖**（M–L）：只读频道、私密频道（指定角色可见）
- [ ] **慢速模式（Slowmode）**（S）：频道内限制发言间隔
- [ ] **操作日志（Audit Log）**（M）：记录踢人、改频道、改角色等管理操作
