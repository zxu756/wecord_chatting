WeCord bot API

Version 2.0. A bot is a member account that a program controls over HTTP. Make bots in Circle settings, Bots; manage tokens, events and availability in Settings, Developer.

Start

BASE=https://<project>.supabase.co/functions/v1/bot-api
TOKEN=<the bot token>
curl -H "Authorization: Bot $TOKEN" $BASE/me

Every request sends Authorization: Bot $TOKEN. Bodies are JSON (at most 32 KB); files are multipart/form-data (at most 8 MB). The token is shown once. Reset it or revoke it in Developer. A bot has exactly the permissions of a member with its roles, and sees only the chats it is in.

In a chat with Advanced chat privacy (restricted: true in /chats) the API gives no message text. Bots can be open to direct chats and group chats: see Developer, Availability. The full description is in openapi.json (OpenAPI 3).

Example: post a poll, then a file

curl -X POST -H "Authorization: Bot $TOKEN" -H "Content-Type: application/json" \
  -d '{"question":"Where to?","options":["Lake","Ridge"]}' $BASE/chats/$CHAT/polls
curl -X POST -H "Authorization: Bot $TOKEN" -F file=@map.png -F caption="Route" $BASE/chats/$CHAT/files

Events only cover chats the bot is in. In a restricted or locked chat, and for disappearing and view-once messages, the event arrives without the text: content_withheld says why. Texts are cut at 4000 characters.

Check every request

Headers: X-WeCord-Timestamp (seconds), X-WeCord-Signature (v1= and the hex HMAC-SHA256 of "<timestamp>.<raw body>" with the secret), X-WeCord-Delivery (an id, for de-duplication) and X-WeCord-Event. Reject a timestamp more than five minutes from your clock. The secret is shown once, when the address is set or reset.

import { createHmac, timingSafeEqual } from "node:crypto";

function verify(secret, headers, rawBody) {
  const ts = Number(headers["x-wecord-timestamp"]);
  if (!Number.isFinite(ts) || Math.abs(Date.now() / 1000 - ts) > 300) return false;
  const expected = "v1=" + createHmac("sha256", secret).update(`${ts}.${rawBody}`).digest("hex");
  const given = headers["x-wecord-signature"] ?? "";
  return given.length === expected.length &&
    timingSafeEqual(Buffer.from(given), Buffer.from(expected));
}

Limits and errors

  • The address must be https:// with a real website name on the usual port. IP addresses, inner names and names that point at inner addresses are refused, before every send. Redirects are not followed. The timeout is 5 seconds.
  • A failed event is tried again after 5 seconds, 30 seconds, 2 minutes, 10 minutes and 1 hour, then lost. 20 lost in a row pause the subscription; saving the address again turns it on. Events older than 6 hours are dropped.
  • At most 300 events a minute and 1000 waiting events per bot; at most 60 writes a minute through the API.
  • Errors are JSON {"error", "message"}: 400 bad body, 401 bad token, 403 not allowed, 404 unknown or not visible, 405 wrong method, 409 conflict, 413 too big, 429 too fast.
